# StyleHub – Responsive Fashion Shopping Website

StyleHub is a modern and responsive fashion shopping landing website developed using HTML and CSS. The project was created as part of the Synent Technologies Web Development Internship Program.

The website provides a premium shopping-style user interface with category-based navigation, product cards, and dedicated pages for fashion products.

## Project Objective

The objective of this project is to design a fully responsive landing page for a product/service with:

- Hero Section
- Features Section
- Footer Section
- Responsive Layout for Mobile and Desktop

In addition to the required features, the project also includes category-based product pages for an improved user experience.

## Features

- Responsive landing page design
- Modern navigation bar
- Hero section with fashion banner
- Product category cards
- Dedicated category pages
- Product cards with images, descriptions, and pricing
- Features section
- Footer section
- Mobile-friendly responsive design
- Professional shopping website UI

## Website Sections

### 1. Hero Section
The landing page includes a modern hero section introducing StyleHub with a premium shopping experience.

### 2. Category Section
Users can browse fashion categories:

- Men Fashion
- Women Fashion
- Shoes
- Watches

Each category opens a dedicated page containing product cards.

### 3. Product Pages
Each category page includes:

- Product images
- Product descriptions
- Pricing details
- Premium responsive card layout

### 4. Features Section
The website includes:

- Premium Quality
- Fast Delivery
- Secure Payments
- 24/7 Support

### 5. Footer Section
A responsive footer is included with branding and copyright details.
